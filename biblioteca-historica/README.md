# Biblioteca histórica de Villa Pelón

## Propósito

Esta biblioteca reúne la investigación histórica necesaria para construir un RPG histórico ambientado en un mundo ficticio llamado **Villa Pelón**, basado en San Patricio del Chañar.

## Capas de información

### 1. Hecho documentado
Dato respaldado por una fuente identificable.

### 2. Interpretación histórica
Explicación razonable de un proceso, siempre diferenciada del hecho.

### 3. Memoria oral
Relato de vecinos, familias, trabajadores o protagonistas. Debe registrarse como memoria/testimonio, no como hecho confirmado automáticamente.

### 4. Ficción jugable
Elementos creados para que el juego funcione: protagonista, misiones, diálogos, personajes compuestos, recompensas, acertijos y acontecimientos inventados.

## Regla de oro

Si un dato no está suficientemente respaldado, **no se presenta como verdad histórica**.
