# Villa Pelón

Un rincón cultural y visual dedicado a San Patricio del Chañar, Neuquén.

## Primera versión
- Sitio estático: HTML, CSS y JavaScript.
- Diseño adaptable a celulares, tabletas y escritorio.
- Historia inicial con distinción entre contexto regional e historia local.
- Curiosidades con enlaces a fuentes.
- Memoria fotográfica con atribución y advertencias de derechos.
- Tres recuerdos imprimibles desde el navegador.
- Sin cuentas, base de datos, backend ni dependencias de instalación.

## Publicación
El proyecto puede publicarse con GitHub Pages desde la rama principal y la carpeta raíz.

## Criterios editoriales
- No presentar recreaciones como fotografías históricas.
- No publicar datos históricos sin fuente identificable.
- Diferenciar hechos locales de contexto regional.
- No reutilizar fotografías de terceros sin autorización.
- Los mapas y documentos se publicarán solo después de verificar sus condiciones de uso.
