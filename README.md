# VILLA PELÓN — Biblioteca Histórica

Proyecto de RPG histórico inspirado en la historia real de **San Patricio del Chañar, Neuquén**.

## Regla central del proyecto

**Villa Pelón es el nombre del mundo/juego. San Patricio del Chañar es la base histórica real.**

El juego podrá ficcionalizar personajes, diálogos, misiones, nombres de lugares internos y situaciones jugables, pero la biblioteca histórica funciona como fuente de verdad para evitar inventar hechos históricos.

## Arquitectura inicial

- `biblioteca-historica/cronologia.json` — línea de tiempo.
- `biblioteca-historica/territorio.json` — territorio, paisaje, agua y transformación.
- `biblioteca-historica/personas-y-comunidades.json` — personas, grupos y actores históricos.
- `biblioteca-historica/vida-y-produccion.json` — agricultura, riego, pelón, trabajo rural, comercio y transformaciones productivas.
- `biblioteca-historica/identidad-y-cultura.json` — nombre, símbolos, fiestas, instituciones y memoria.
- `biblioteca-historica/fuentes.json` — fuentes y nivel de confianza.
- `biblioteca-historica/README.md` — reglas para ampliar la biblioteca.

## Principio narrativo

No queremos hacer una enciclopedia disfrazada de juego.

Queremos que el jugador **descubra la historia jugando**: caminar, observar, conversar, investigar, encontrar objetos, reconstruir fotografías, resolver problemas, visitar lugares y relacionar pistas.

La biblioteca es el motor invisible que permitirá construir ese mundo con profundidad.
