# Villa Pelón · Un rincón bien chañarense

Museo digital comunitario e independiente dedicado a San Patricio del Chañar, Neuquén.

## Qué incluye
- Diseño editorial adaptable a celular, tablet y escritorio.
- Navegación sencilla por historia, territorio, memoria, curiosidades, Fiesta del Pelón y recuerdos.
- Cronología ampliada con fuentes oficiales, académicas y periodísticas identificadas.
- Contenido sobre el paisaje del valle inferior del río Neuquén, el riego, la fruticultura y la identidad local.
- Fotografías de la muestra “Huellas, Agua y Tierra” con atribución; no se presentan como fotos de libre uso.
- Seis piezas imprimibles originales desde el navegador.
- Sin cuentas, publicidad, backend, base de datos ni instalaciones.

En GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Criterios editoriales
- Diferenciar historia local de contexto regional.
- Distinguir fuentes oficiales, estudios técnicos, artículos periodísticos y trabajos científicos.
- No publicar datos actuales a partir de estadísticas antiguas sin fecha.
- No presentar recreaciones como fotografías históricas.
- No reutilizar fotografías de terceros sin autorización.
- Incorporar testimonios con nombre, fecha y consentimiento.
- No publicar mapas, ubicaciones ni teléfonos sin verificación.

## Experiencia multidispositivo y accesibilidad
- Navegación adaptada a pantallas pequeñas, medianas y grandes.
- Tarjetas reordenables por CSS sin perder el orden de lectura.
- Mini juego de tres preguntas con datos documentados.
- Controles locales para aumentar/disminuir el tamaño de lectura y activar mayor contraste.
- Compartir mediante el menú nativo del dispositivo cuando el navegador lo permite.
- Soporte para movimiento reducido y foco de teclado visible.
- No usa cuentas, cookies propias, almacenamiento de datos personales ni servicios pagos.
