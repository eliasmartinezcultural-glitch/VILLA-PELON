# Motor Vivo de Villa Pelón

Este directorio define la arquitectura conceptual del motor RPG multidispositivo.

## Principio

Las bibliotecas históricas no son documentos aislados: forman una **red de conocimiento**.

Cada hecho puede conectarse con:
- lugares
- épocas
- personajes
- objetos
- instituciones
- fotografías
- fuentes
- misiones
- diálogos
- clima
- cambios del paisaje
- consecuencias jugables

El juego consulta esa red para generar una experiencia coherente.

## Mundo vivo

El mundo debe contemplar desde el inicio:
- ciclo día/noche
- calendario
- estaciones
- clima dinámico
- personajes con rutinas
- lugares con horarios
- misiones principales y secundarias
- diálogos contextuales
- descubrimientos
- inventario
- cuaderno de Luna
- progresión histórica
- memoria persistente del jugador
- guardado local
- adaptación PC/teléfono/tablet

## Regla técnica

Primero se diseña el sistema de datos y las conexiones; después la interfaz. La representación visual podrá cambiar sin destruir la biblioteca ni las relaciones históricas.
