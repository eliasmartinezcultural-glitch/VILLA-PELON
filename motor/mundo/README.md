# Primera capa mundial · Villa Pelón

Esta carpeta define la **primera capa mundial** del RPG histórico.

Orden de construcción:

1. reglas mundiales
2. mapa y zonas
3. ciclo día/noche
4. clima
5. transiciones
6. NPC y rutinas
7. misiones
8. historia y bibliotecas
9. presentación visual

La regla central es: **primero construir un mundo coherente; después llenarlo de contenido.**

Villa Pelón es el nombre del mundo del juego. San Patricio del Chañar es su base histórica real.
